Vorlese-Text (Teleprompter)

Diesen Text liest der Bewerber in die Kamera; das Tempo bestimmt er selbst. Platzhalter wie [dein Name] ruhig stehen lassen.

Sicherheit

📱 Geräte-Bindung

Ist sie eingeschaltet, dürfen sich nur freigegebene Geräte im Admin-Bereich anmelden – alle anderen werden abgewiesen, selbst mit richtigem Passwort. Standardmäßig ist sie aus, damit man sich nicht versehentlich aussperrt. Du entscheidest, wann es losgeht.

Neues Gerät hinzufügen

Notausgang, falls kein Gerät mehr geht: in Coolify ADMIN_DEVICE_LOCK=off setzen und Redeploy – dann zählt nur noch das Passwort.

🔐 Zusätzlicher Code beim Login optional

Du musst hier nichts einrichten – der Login mit Passwort und freigegebenem Gerät funktioniert auch ohne. Wer mag, kann zusätzlich einen 6-stelligen Code verlangen (Google Authenticator). Notausgang: in Coolify ADMIN_2FA_OFF=1 setzen und Redeploy.
